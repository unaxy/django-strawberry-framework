# DRY 0.0.15 (3): to-do list

Candidates from a second, thread-driven sweep at `078b6d00`. The 50 items of `dry-0_0_15_2.md` fell into eight
patterns; six read-only Opus passes hunted more instances of each across `django_strawberry_framework/`:

- T1: the owner exposes half a fact, so sites hand-compose the rest
- T2: an MRO read where the contract is the class's own value
- T3: a local re-implementation of a `utils/truth.py` / `utils/_narrowing.py` / `utils/typing.py` primitive
- T4: one name grammar or Django fact spelled or detected twice
- T5: dead knobs and one-caller indirection (DRY.md principle 11)
- T6: one rule written per flavor, or enforced on some members only (axis 6)
- T7: prose restating counts, readers, history or false claims
- T8: user-facing recourse naming a fix that does not exist or does not work

Every item is a candidate, not a plan: each ACT gets the research pass (trace to root, check upstream, write the plan),
then lands with its tick. Line numbers are at `078b6d00`. Proofs are behavioral (DRY.md principle 9); no census or AST
gate lands. Items excluded as already landed in `dry-0_0_15_2.md` are not repeated.

Progress: 2 done. 2 security (maintainer first), 33 ACT, 16 DECIDE, 3 pin gap, 2 CHANGELOG entries.

Landing order: the security items (1-3) first, by the [SECURITY.md][security] path; 32 after 3; 14 and 22 share
`inspect_django_type`; 39 before 7's example text.
